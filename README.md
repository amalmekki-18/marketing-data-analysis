# 📊 Analyse de données marketing

## 📌 Description

Ce projet consiste en une analyse de données marketing afin de comprendre le comportement des clients et prédire leur réponse à une campagne.

## ⚙️ Technologies utilisées

* Python
* Pandas, NumPy
* Matplotlib / Seaborn
* Scikit-learn

## 🔍 Étapes du projet

* Nettoyage et prétraitement des données
* Analyse exploratoire (EDA)
* Implémentation d’un modèle KNN
* Régression linéaire
* Évaluation des performances (Accuracy, MSE)

## 📈 Résultats

* Modèle KNN utilisé pour prédire les réponses clients
* Analyse des relations entre âge, dépenses et comportement

## 🎯 Objectif

Aider à la prise de décision marketing basée sur les données.
